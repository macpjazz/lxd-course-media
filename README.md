# lxd-course-media

Images and audio for LXDStudios eLearning courses, loaded by Rise 360 Code blocks and web objects.
Course pages link to a fixed version tag through jsDelivr, so later changes never break a live course:

    https://cdn.jsdelivr.net/gh/macpjazz/lxd-course-media@<tag>/<course>/<block>/<file>

## Contents

- `hear-calm-connect/ray-first-minute/` (tag v1): Ray's first minute, Hear. Calm. Connect. portfolio course.
  Counter background, Ray in 4 moods, 7 voice lines (R01, R04, R05, R06, R12, R20, R21).

Characters, places and the city of Westbrook are fictional. Course design by Mark Diaz, LXDStudios.
https://markdiazlxd.netlify.app/
