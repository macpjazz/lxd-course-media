# lxd-course-media

Images and audio for LXDStudios eLearning courses, loaded by Rise 360 Code blocks and web objects.
Course pages link to a fixed version tag, so later changes never break a live course:

    https://raw.githubusercontent.com/macpjazz/lxd-course-media/<tag>/<course>/<block>/<file>

(jsDelivr returned 503 on the mp3 files on 2026-10-15, so courses use GitHub's direct links.)

## Contents

- `hear-calm-connect/ray-first-minute/`: Ray's first minute, Hear. Calm. Connect. portfolio course.
  - v1: counter background, Ray in 4 moods (still pictures), 7 voice lines (R01, R04, R05, R06, R12, R20, R21).
  - v2: adds Ray's talking clips for the same 7 lines (voice built in) and 4 idle loops (upset, angry, guarded,
    relieved). H.264 + AAC, 1280x720, faststart. The stills and mp3s stay as the fallback.

Characters, places and the city of Westbrook are fictional. Course design by Mark Diaz, LXDStudios.
https://markdiazlxd.netlify.app/
